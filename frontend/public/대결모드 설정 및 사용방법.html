02

사전 1회 필수 설정 (전시회 전 준비)

전시회 시작 전 개발 PC와 Quest 2 두 대에 미리 1회만 설정해 두면 당일 즉시 구동됩니다.

STEP 1

서버 PC Windows 방화벽 포트(3000, 8000) 허용

Quest 2 헤드셋이 PC의 웹 게임과 WebSocket 중계 서버로 접속할 수 있도록 포트를 개방합니다.

방법: Windows 시작 메뉴에서 PowerShell 검색 ➔ [관리자 권한으로 실행] 후 아래 명령어 실행:

PowerShell (관리자 권한) 
New-NetFirewallRule -DisplayName "VR Game Web (3000)" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
New-NetFirewallRule -DisplayName "VR Game Relay (8000)" -Direction Inbound -LocalPort 8000 -Protocol TCP -Action Allow
STEP 2

Quest 2 #1 & #2 WebXR 보안 정책 해제 (★매우 중요★)

Meta Quest 브라우저는 W3C 보안 규정상 http://192.168.x.x와 같은 사설 IP 접속 시 WebXR(VR 세션) 진입을 기본 차단합니다.
아래 절차를 Quest 2 헤드셋 두 대 모두 각각 1회씩 진행해주세요.

  1. Quest 2 착용 ➔ 기본 탑재된 [Meta Quest 브라우저] 실행
  2. 주소창에 chrome://flags 입력 후 이동
  3. 상단 검색창에 insecure 검색 ➔ Insecure origins treated as secure 항목 찾기
  4. 입력창에 아래 주소를 등록:
    Insecure Origins 등록 문자열 
    http://192.168.0.50:3000,http://192.168.0.50:8000
  5. 우측 드롭다운 메뉴를 [Disabled] ➔ [Enabled] 로 변경
  6. 화면 우측 하단에 뜨는 파란색 [Relaunch] 버튼을 눌러 브라우저 재시작
✓ 이 설정을 1회 해두면 별도의 복잡한 사설 SSL(HTTPS) 인증서 설치 없이 360도 Immersive-VR 사격장에 100% 정상 진입합니다!
STEP 3

서버 PC 게임 패키지 설치 (코드를 새로 받을 때마다 1회)

📌 이유: 주소 뒤에 ?role=spectator가 붙어있어 선수 슬롯(1P, 2P)을 차지하지 않고 순수 관람객으로 고정됩니다.
🖥️ 화면: 경기가 없을 때는 AI 시연(사격·명중 효과음만 작게)을 배경으로 대기 화면(게임 소개 · 표적 점수 · 다음 도전자 · 최근 경기)이 나오고, 경기가 시작되면 LIVE 중계, 끝나면 결과 화면(20초)으로 자동으로 바뀝니다.
🔊 음향: 브라우저 정책상 화면을 한 번 클릭해야 소리가 납니다. 소리가 막혀 있으면 TV 오른쪽 위에 "화면을 한 번 클릭하면 소리가 나요"가 뜨니 화면을 한 번 클릭하세요(F11·Esc로는 켜지지 않음). PC 스피커 볼륨을 켜두어 타격음과 한국어 음성 안내가 부스 전체에 울리도록 합니다.
🎚️ TV 소리 켜기·끄기: 오른쪽 위 [소리 끄기]/[소리 켜기] 버튼(마우스를 움직이면 나타남) 또는 M 키. 소리 설정은 기기마다 저장되어 새로고침해도 그대로입니다.
⚡ 클릭 없이 소리 내기(권장): 크롬(엣지도 같음) 바로가기 › 속성 › 대상 끝에 --autoplay-policy=no-user-gesture-required --user-data-dir=C:\booth-tv --kiosk http://localhost:3000/?role=spectator를 붙여 실행합니다. 크롬이 이미 켜져 있어도 옵션이 적용되고 전체 화면으로 열립니다(닫기: Alt+F4).

실시간 1:1 대결의 핵심 플레이 요소와 관람석 모니터의 카메라 전환 조작법입니다.

IN-GAME RULES

🥊 1:1 실시간 선착순 점수 쟁탈전

  • 경기 시작 (둘 다 준비되면 시작): 선수가 VR에 들어간 순간(또는 경기 후 컨트롤러 방아쇠(트리거))이 "준비 완료"입니다. 두 선수가 모두 준비되면 60초 경기가 바로 함께 시작되고, 게이트 위 점수판에 "GO!"가 크게 뜹니다. 한 명만 준비하면 15초 뒤 자동으로 시작하며, 늦은 선수는 PC 화면으로 경기에 들어가 있다가 오른쪽 위 [VR로 이어서]를 누르면 됩니다. 상대 헤드셋은 그 기기에서 직접 버튼을 눌러야 VR에 들어갈 수 있으므로(브라우저 보안 규칙), 두 선수 모두 헤드셋을 쓴 뒤 각자 [VR 배틀 시작]을 누르게 안내하세요. 관전 화면에는 [경기 시작]이 없습니다. 경기는 선수가 준비해야 시작하고, 관전 PC는 보기 · 일시정지 · 중단만 합니다.
  • 경기 후 3초 결과 보기: 경기가 끝나면 막판에 쏘던 방아쇠로 바로 다음 경기가 시작되지 않도록 3초 동안 결과판만 보여 줍니다. 그다음 방아쇠를 당기면 다시 준비합니다.
  • 🎯 표적 8개 키워드 & 차등 배점 (핵심!):
      • ★ 2점 표적 (보너스): 정보, 통신 (정보통신과 핵심전공 표적, 황금빛 발광)
      • ● 1점 표적 (기본): 제어, 회로, 인공, 전자 (기초전공 표적)
      • ▼ -1점 표적 (감점): 기계, 전기 (라벨에 빨간 "-1점". 맞히면 1점이 깎이고 연속 명중이 끊기며 명중 수에 들어가지 않음. 맞히지 않으면 8초 뒤 사라짐, 한 번에 난이도별 1 · 2 · 3개까지. AI도 피함)
  • 동일 타겟 선착순 격파: 같은 표적을 먼저 맞춘 선수만 점수를 얻으며, 즉시 폭발 효과와 함께 사라져 중복 타격이 방지됩니다.
  • 6DoF 모션 아바타: 상대 선수는 바이저 헬멧과 이름표(1P · 2P · AI)로 보이며, 시선 회전과 총구 방향, 발사 레이저가 실시간으로 부드럽게 따라옵니다.
  • 재장전: 탄약 10발 소진 시 컨트롤러 그립 버튼을 쥐어 재장전합니다. 총 위 작은 화면에 남은 시간 · 내 점수 · 상대 점수 · 탄약 10칸이 보입니다.
  • 승패 결과: 60초가 끝나면 "TIME UP"과 함께 눈앞에 결과판(승자 · 점수 · 명중 · 명중률 · 최고 연속 명중)이 나오고, 한국어 음성으로 결과를 알려 줍니다. 한 발도 쏘지 않은 선수의 명중률은 "-"로 표시됩니다.
  • 🛑 운영자 긴급 경기 중단 (ESC 키): 돌발 상황 발생 시 관전 모니터 PC 키보드의 ESC 또는 화면 오른쪽 위 [경기 중단] 버튼(마우스를 움직이면 나타남)을 누르면 양측 헤드셋 경기가 즉시 안전하게 중단되고 초기화됩니다. 설정 · 순위표 창이 열려 있으면 ESC는 창만 닫고 경기는 계속되므로, 중단하려면 한 번 더 누르세요(누르고 있는 것으로는 중단되지 않음).
  • 🚪 VR 모드 종료 & 웹 브라우저 복귀: 경기가 끝난 뒤 컨트롤러 그립 또는 A·B(X·Y) 버튼을 누르면 VR이 끝나고 브라우저 첫 화면으로 돌아갑니다. 경기 도중 멀미 등 긴급 상황에는 A·B(X·Y) 버튼을 1초 넘게 길게 누르면 경기를 중단하고 나갑니다(총 화면에 "VR 종료 N초" 표시).

🔄 다음 관람객 연속 라운드 진행법

경기가 끝나면 브라우저를 새로고침할 필요가 없습니다!
다음 학생이 헤드셋을 착용한 뒤, 컨트롤러 방아쇠(트리거)를 다시 당기거나 선수 PC 화면 오른쪽 위 [경기 시작](결과창에서는 [재경기 시작])을 누르면 준비 완료가 되고, 두 선수가 모두 준비하면(혼자면 바로) 스코어 0:0으로 새 라운드가 시작됩니다. 관전 PC에서는 시작할 수 없습니다.

⚡ 헤드셋 화면 꺼짐(Sleep) 대처법

학생들이 헤드셋을 벗어두어 대기 모드에 들어간 경우, 다시 착용했을 때 WebSocket이 재연결됩니다.
만약 연결이 끊겼다면 브라우저 상단 [새로고침(F5)]을 한 번 누르고 [VR 배틀 시작]을 누르면 즉시 복구됩니다.

📡 Wi-Fi IP가 변경되었을 때

전시회장 현장 공유기에 연결하면서 PC IP가 변경된 경우, CMD에서 ipconfig로 새 IP를 확인한 후 Quest 2 주소창에 새 IP로 접속하세요.
(사전 설정했던 flags 설정은 IP 대역이 크게 바뀌지 않는 한 유지됩니다.)

🎨 경기장 테마 · 표적 · 난이도 바꾸기

경기 설정(경기장 테마 · 표적 모양 · 난이도)은 모든 화면(1P · 2P · 관전) 공통입니다. 관전 PC를 포함해 아무 기기의 [환경설정] › 경기 설정에서 바꾸면 모든 화면이 함께 바뀝니다. 경기 중에는 바꿀 수 없습니다.
테마를 바꾸면 경기장을 새로 지어 화면이 잠깐 멈추므로 선수가 헤드셋을 쓰기 전에 바꾸세요. 서버를 다시 켜면 기본값(사이버 아레나 · 드론 · 보통)으로 돌아갑니다.
화면마다 다르게 보이면, 업데이트 뒤 새로고침하지 않은 화면이 있거나 서버가 예전 코드인 경우입니다. 서버를 새 코드로 다시 켜고 모든 화면을 새로고침하세요.

🐢 VR이 끊기거나 느릴 때

주소 끝에 &debug=perf를 붙여 접속하면(예: ?role=p1&debug=perf) 총을 들지 않은 손 옆에 fps가 보입니다. Quest 2는 72fps가 정상입니다.
Quest는 자동으로 낮은 그래픽 품질을 쓰며, PC 관전 화면이 느리면 주소에 &quality=low를 붙이세요.
