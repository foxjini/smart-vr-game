02

사전 1회 필수 설정 (전시회 전 준비)

전시회 시작 전 개발 PC와 Quest 2 두 대에 미리 1회만 설정해 두면 당일 즉시 구동됩니다.

STEP 1

서버 PC Windows 방화벽 포트(3000, 8000) 허용

Quest 2 헤드셋이 PC의 웹 게임과 WebSocket 중계 서버로 접속할 수 있도록 포트를 개방합니다.

방법: Windows 시작 메뉴에서 PowerShell 검색 ➔ [관리자 권한으로 실행] 후 아래 명령어 실행:

PowerShell (관리자 권한) 
New-NetFirewallRule -DisplayName "VR Game Web (3000)" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
New-NetFirewallRule -DisplayName "VR Game Relay (8000)" -Direction Inbound -LocalPort 8000 -Protocol TCP -Action Allow
STEP 2

Quest 2 #1 & #2 WebXR 보안 정책 해제 (★매우 중요★)

Meta Quest 브라우저는 W3C 보안 규정상 http://192.168.x.x와 같은 사설 IP 접속 시 WebXR(VR 세션) 진입을 기본 차단합니다.
아래 절차를 Quest 2 헤드셋 두 대 모두 각각 1회씩 진행해주세요.

  1. Quest 2 착용 ➔ 기본 탑재된 [Meta Quest 브라우저] 실행
  2. 주소창에 chrome://flags 입력 후 이동
  3. 상단 검색창에 insecure 검색 ➔ Insecure origins treated as secure 항목 찾기
  4. 입력창에 아래 주소를 등록:
    Insecure Origins 등록 문자열 
    http://192.168.0.50:3000,http://192.168.0.50:8000
  5. 우측 드롭다운 메뉴를 [Disabled] ➔ [Enabled] 로 변경
  6. 화면 우측 하단에 뜨는 파란색 [Relaunch] 버튼을 눌러 브라우저 재시작
✓ 이 설정을 1회 해두면 별도의 복잡한 사설 SSL(HTTPS) 인증서 설치 없이 360도 Immersive-VR 사격장에 100% 정상 진입합니다!

기기별 접속 순서 (★슬롯 꼬임 방지★)

플레이어 슬롯(1P, 2P)과 관람객(Spectator) 역할을 완벽히 구분하기 위해 반드시 아래 순서대로 접속하세요.

1순위

[서버 PC 모니터] 관람 중계 화면 먼저 열기

SPECTATOR

서버 PC의 브라우저(크롬 또는 엣지)에서 아래 주소로 접속한 후, 키보드 F11을 눌러 전체화면으로 만듭니다:

서버 PC 브라우저 주소창 
http://localhost:3000/?role=spectator

📌 이유: 주소 뒤에 ?role=spectator가 붙어있어 선수 슬롯(1P, 2P)을 차지하지 않고 순수 관람객으로 고정됩니다.
🔊 음향: PC 스피커 볼륨을 켜두어 BGM, 타격음, 한국어 오퍼레이터 음성이 부스 전체에 박진감 있게 울리도록 합니다.

IN-GAME RULES

🥊 1:1 실시간 선착순 점수 쟁탈전

  • 경기 시간: 두 선수 중 아무나 컨트롤러 방아쇠(트리거)를 당기면 60초 카운트다운과 함께 동시 스타트!
  • 🎯 표적 6대 키워드 & 차등 배점 (핵심!):
      • ★ 2점 표적 (보너스): 정보, 통신 (정보통신과 핵심전공 표적, 황금빛 발광)
      • ● 1점 표적 (기본): 제어, 회로, 인공, 전자 (기초전공 표적)
  • 동일 타겟 선착순 격파: 같은 표적을 먼저 맞춘 선수만 점수를 얻으며, 즉시 폭발 파티클과 함께 소멸되어 중복 타격이 방지됩니다.
  • 6DoF 모션 아바타: 상대방 헬멧 시선 회전, 블래스터 총구 방향, 발사 시 화염(Muzzle Flash)이 가상 공간에 실시간(20Hz) 표시됩니다.
  • 재장전: 탄약 10발 소진 시 컨트롤러 그립 버튼을 쥐어 에너지 셀을 재장전합니다.
  • 승패 브리핑: 60초 종료 시 승자에게 "VICTORY", 패자에게 "DEFEAT" 한국어 오퍼레이터 음성이 출력됩니다.
  • 🛑 운영자 긴급 경기 중단 (ESC 키): 돌발 상황 발생 시 서버 PC 키보드의 ESC 또는 상단 [경기 중단] 버튼을 누르면 양측 헤드셋 경기가 즉시 안전하게 중단되고 초기화됩니다.
  • 🚪 VR 모드 종료 & 웹 브라우저 복귀: 경기 종료 후 컨트롤러 그립 또는 메뉴 버튼을 누르면 3D VR 세션이 종료되고 일반 브라우저 초기 화면(Welcome)으로 즉시 복귀합니다. (경기 도중 멀미 발생 시 메뉴/보조 버튼을 1.2초 길게 누르면 긴급 탈출 가능)

전시회 부스 운영 꿀팁 & 트러블슈팅

🔄 다음 관람객 연속 라운드 진행법

경기가 끝나면 브라우저를 새로고침할 필요가 없습니다!
다음 학생이 헤드셋을 착용한 뒤, 컨트롤러 방아쇠(트리거)를 다시 당기거나 PC에서 사격 시작을 누르면 스코어가 0:0으로 리셋되며 즉시 새 라운드가 시작됩니다.

⚡ 헤드셋 화면 꺼짐(Sleep) 대처법

학생들이 헤드셋을 벗어두어 대기 모드에 들어간 경우, 다시 착용했을 때 WebSocket이 재연결됩니다.
만약 연결이 끊겼다면 브라우저 상단 [새로고침(F5)]을 한 번 누르고 [VR 배틀 출격]을 누르면 즉시 복구됩니다.

📡 Wi-Fi IP가 변경되었을 때

전시회장 현장 공유기에 연결하면서 PC IP가 변경된 경우, CMD에서 ipconfig로 새 IP를 확인한 후 Quest 2 주소창에 새 IP로 접속하세요.
(사전 설정했던 flags 설정은 IP 대역이 크게 바뀌지 않는 한 유지됩니다.)
