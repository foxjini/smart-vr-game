⚡ 빠른 시작 가이드 (Quick Start - 3분 요약)

이미 환경 설정이 완료된 상태에서 게임을 바로 구동하는 3단계 요약입니다. 코드를 새로 받았다면 STEP 2 전에 npm install을 한 번 실행하세요.

STEP 1

FastAPI 중계 서버 구동

IoT 하드웨어 및 6DoF 자세를 실시간 동기화하는 WebSocket 중계 서버를 실행합니다.

Terminal 1 (server/) 
cd server
python run.py
✓ 포트 8000 실행 확인 (WebSocket 준비)
STEP 2

Next.js 3D 게임 구동

Three.js 3D 그래픽 및 WebXR 세션을 렌더링하는 웹 애플리케이션을 구동합니다.

Terminal 2 (frontend/) 
cd frontend
npm run dev
✓ 포트 3000 실행 확인 (Turbopack 개발 서버)
STEP 3

Quest 2 브라우저 접속

동일 Wi-Fi에 연결된 Meta Quest 2 브라우저에서 개발 PC의 IP로 접속하여 플레이합니다.

Quest 2 Browser URL 
http://192.168.1.150:3000
✓ [VR 배틀 시작]을 누르면 VR에 들어가 준비 완료 (친구 대결은 둘 다 준비하면 시작, 혼자면 바로 AI 대결)

📦 1. 게임 설치 및 설정 가이드 (Game Installation & Setup)

개발 PC 환경(Windows / macOS / Linux)에서 백엔드 중계 서버와 프론트엔드 웹 게임을 처음 설치하고 실행하는 단계별 공식 절차입니다.

01

사전 필수 런타임 및 네트워크 환경 준비

본 게임 시스템을 원활하게 구동하기 위해 아래 런타임 및 네트워크 조건을 확인합니다.

  • Node.js: v20.9 이상 (Next.js 16 필수 조건, v22 LTS 권장, 터미널에서 node -v 로 확인)
  • Python: v3.10 이상 권장 (터미널에서 python --version 으로 확인)
  • 동일 Wi-Fi 네트워크: 개발 PC와 Meta Quest 2 헤드셋이 반드시 동일한 공유기(같은 서브넷)에 연결되어 있어야 합니다.
📌 개발 PC의 사설 IP(IPv4) 확인 방법:
Windows PowerShell 또는 명령 프롬프트(CMD)에서 ipconfig 실행 → 무선 LAN 어댑터의 IPv4 주소(예: 192.168.1.150 또는 192.168.137.1)를 메모해 두세요. 상단 유틸리티 툴바의 입력란에 넣으면 문서 전체에 즉시 동기화됩니다.
02

FastAPI WebSocket 통신 중계 서버 설치 및 실행

FastAPI 서버는 Wii 눈차크/Pico 2 W 하드웨어 신호, Quest 2 6DoF 자세 좌표(20Hz), 사격 이벤트, 타겟 피격 검증을 클라이언트 간에 실시간 중계합니다.

PowerShell / Bash (server/ 디렉토리) 
# 1. 서버 디렉토리 이동
cd server

# 2. 필수 라이브러리 설치 (FastAPI, Uvicorn, WebSockets 등)
pip install -r requirements.txt

# 3. 중계 서버 백그라운드 구동
python run.py
💡 서버 구동 검증 방법
브라우저에서 http://localhost:8000/api/status에 접속하여 아래와 같이 정상 JSON이 응답되는지 확인합니다.
{"pico_connected":false, "game_clients_count":0, "status":"online"}
Swagger 대화형 API 문서는 http://localhost:8000/docs에서 열람 가능합니다.
03

Next.js 16 웹 게임 클라이언트 설치 및 실행

Next.js 16 (Turbopack, TypeScript) 기반의 3D 사격장 웹 애플리케이션 의존성을 설치하고 개발 서버를 가동합니다.

PowerShell / Bash (frontend/ 디렉토리) 
# 1. 프론트엔드 디렉토리 이동
cd frontend

# 2. npm 패키지 의존성 설치 (처음 한 번 + 코드를 새로 받을 때마다 한 번)
npm install

# 3. 개발 서버 구동 (포트 3000)
npm run dev
⚙️ Next.js 서브넷 IP 허용 설정 (HMR 및 Cross-Origin 차단 방지):
frontend/next.config.ts 파일의 allowedDevOrigins 목록에 개발 PC의 IP 대역이 포함되어 있으므로, 사설 네트워크의 Quest 2 및 모바일 기기에서도 리소스 차단 없이 100% 정상 로드됩니다.
💡 업데이트 후 npm install · 인터넷 없이 실행
VR 안 글자를 그리는 troika-three-text 패키지가 추가되었습니다. 예전 node_modules로 실행하면 Module not found: troika-three-text 오류가 나므로, 코드를 새로 받았다면 npm install을 한 번 실행하세요.
화면 글꼴(Pretendard · Rajdhani)은 frontend/public/fonts/에 내장되어 있어, 설치가 끝난 뒤에는 인터넷이 없는 전시장에서도 그대로 보입니다.

서버가 구동되면 개발 PC 브라우저에서 http://localhost:3000으로 접속하여 메인 메뉴(게임 소개 · 대결 규칙 · 조작 방법)가 나타나는지 확인합니다.

04

Windows 방화벽 인바운드 포트 허용 (3000, 8000번 포트)

Quest 2가 PC로 접속할 수 있도록 Windows 방화벽에서 포트 3000(Next.js)과 8000(FastAPI)을 허용합니다.

PowerShell (관리자 권한으로 실행) 
# 3000번(Next.js) 및 8000번(FastAPI) 인바운드 방화벽 규칙 추가
New-NetFirewallRule -DisplayName "Nunchuk VR Game (3000)" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
New-NetFirewallRule -DisplayName "Nunchuk VR Relay (8000)" -Direction Inbound -LocalPort 8000 -Protocol TCP -Action Allow

🥽 2. Meta Quest 2 설치 및 설정 가이드 (Quest 2 WebXR Setup)

Meta Quest 2 / Quest 3 헤드셋을 착용하고 사설 IP(HTTP) 환경에서 W3C 보안 정책을 해제하여 360도 몰입형 WebXR 사격장으로 진입하는 공식 설정법입니다.

⚠️ W3C WebXR 보안 정책 (Secure Context 요구사항) 필독!
Chromium 기반 Meta Quest 브라우저는 W3C 명세에 따라 사설 IP(예: http://192.168.1.150:3000) 접속 시 보안상 WebXR 진입을 기본 차단합니다.
하지만 아래의 1분 설정을 1회만 적용하면, 복잡한 사설 SSL 인증서 설치 없이 안전한 출처(Secure Origin)로 등록되어 360도 Immersive-VR 모드가 무제한 정상 구동됩니다.
01

헤드셋 Wi-Fi 네트워크 동일 공유기 연결 확인

Quest 2 헤드셋의 빠른 설정(Quick Settings) → Wi-Fi 메뉴로 이동하여 개발 PC와 동일한 무선 공유기 SSID에 연결되어 있는지 확인합니다.

💡 5GHz Wi-Fi 환경을 권장하며, 공유기 간 무선 격리(AP Isolation) 옵션이 꺼져 있어야 장치 간 통신이 가능합니다.
02

Quest 2 브라우저 실험적 플래그(chrome://flags) 진입

Quest 2 헤드셋 내부에서 기본 탑재된 [Meta Quest 브라우저] 앱을 실행한 후, 주소창에 아래 주소를 입력하고 이동합니다.

Quest 2 Browser Address Bar 
chrome://flags
03

Insecure origins treated as secure 검색 및 개발 PC IP 등록

실험적 설정 화면 최상단의 [Search flags] 검색창에 insecure를 입력합니다.

검색어: Insecure origins treated as secure

검색 결과로 나타난 해당 항목에서 아래 작업을 순서대로 진행합니다:

  1. 텍스트 입력란에 개발 PC의 주소를 쉼표로 구분하여 입력:
    http://192.168.1.150:3000,http://192.168.1.150:8000
  2. 우측 드롭다운 선택 메뉴를 [Disabled]에서 [Enabled]로 변경합니다.
04

브라우저 재시작(Relaunch) 및 WebXR 사격장 진입

설정을 변경하면 화면 우측 하단에 파란색 [Relaunch] 버튼이 표시됩니다. 이 버튼을 클릭하여 브라우저를 재부팅합니다.

재시작된 브라우저 주소창에 개발 PC 게임 주소를 입력하고 접속합니다:

Quest 2 Browser Address 
http://192.168.1.150:3000
🥽 VR 사격장으로 들어가는 방법
메인 메뉴의 [VR 배틀 시작] 버튼(또는 화면 오른쪽 위 [VR 시작])을 터치합니다.
헤드셋 공간 권한 허용 팝업이 뜨면 [허용]을 선택하세요. 경기장으로 시야가 바뀌면서 바로 경기가 시작됩니다!
주소 끝에 ?role=p1(2P 헤드셋은 ?role=p2)을 붙여 접속하면 이 헤드셋의 역할이 고정됩니다.

🔌 3. 하드웨어 결선 가이드 (Wii Nunchuk ↔ Pico 2 W)

Nintendo Wii 눈차크의 I2C 커넥터와 Raspberry Pi Pico 2 W의 핀맵 결선도 및 무선 펌웨어 배포 안내입니다.

PINOUT MAP

눈차크 ↔ Pico 2 W 결선도

Wii Nunchuk Plug Pinout 
       [Wii Nunchuk Plug]
          +---------+
          |  [---]  |  <- 상단 노치
          | 1  2  3 |
          | 4  5  6 |
          +---------+
    1: GND      (White)  -> Pico 2 W Pin 38 (GND)
    2: VCC 3.3V (Red)    -> Pico 2 W Pin 36 (3V3 OUT)
    3: SCL      (Yellow) -> Pico 2 W Pin 7  (GP5 / I2C0 SCL)
    4: NC
    5: NC
    6: SDA      (Green)  -> Pico 2 W Pin 6  (GP4 / I2C0 SDA)

I2C 풀업 저항은 내부 풀업을 활용하거나 4.7kΩ 저항을 3.3V에 연결할 수 있습니다.

CIRCUITPYTHON

Pico 2 W 펌웨어 설정 (settings.toml)

CIRCUITPY/settings.toml 
CIRCUITPY_WIFI_SSID = "My_WiFi_SSID"
CIRCUITPY_WIFI_PASSWORD = "My_Password"
SERVER_HOST = "192.168.1.150"
SERVER_PORT = "8000"

firmware/code.py와 settings.toml을 Pico 2 W 드라이브 루트에 복사하면 전원 인가 즉시 Wi-Fi에 접속하여 50Hz 고속 센서 패킷을 WebSocket 서버로 송신합니다.

🎮 4. 게임 종합 사용 설명서 (Comprehensive Gameplay Guide)

VR 경기 시작·종료 흐름, 4가지 컨트롤러 조작법, 10발 탄창 및 재장전 룰, 가상 블래스터 OLED 디스플레이를 안내합니다.

VR MATCH FLOW

⚡ VR에 들어가면 준비 완료, 둘 다 준비되면 시작

VR 헤드셋을 쓴 채로 2D 메뉴 버튼을 조준할 필요가 없습니다.
AI 대결(혼자 접속)은 VR 사격장에 들어가면 바로 경기가 시작되고, 게이트 위 점수판에 "GO!"가 크게 떴다 사라지며 60초가 흐르기 시작합니다.
친구 대결(1P·2P 모두 접속)은 VR에 들어간 순간이 "준비 완료"입니다. 눈앞에 "대결 준비" 판이 나오고, 두 선수가 모두 준비되면 바로 시작합니다. 한 명만 준비하면 15초 뒤 자동으로 시작하고, 늦은 선수는 PC 화면으로 경기에 들어가 있다가 오른쪽 위 [VR로 이어서]를 누르면 됩니다. 상대 헤드셋은 그 기기에서 직접 버튼을 눌러야 VR에 들어갈 수 있어서(브라우저 보안 규칙) 먼저 준비한 쪽이 기다려 줍니다. 기다리는 동안 상대 화면 위쪽에는 "1P가 준비했어요!"와 시작 버튼, 남은 초가 나옵니다.
60초가 끝나면 "TIME UP"과 함께 눈앞에 결과판이 나타납니다. 막판에 쏘던 방아쇠로 바로 넘어가지 않게 3초 동안은 결과만 보여 주고, 그다음 방아쇠(Trigger)를 당기면 다시 준비합니다. 그립 또는 A·B 버튼을 누르면 VR에서 나갑니다(상대를 기다리는 중에는 그립이 아니라 A·B 버튼으로 나갑니다).

🔫 사격 및 10발 탄창 룰

  • 초기 탄약: 라운드 시작 시 10발 완충 상태로 시작합니다.
  • 탄약 고갈: 잔탄 0발 시 총알이 발사되지 않으며 둔탁한 공이치기 사운드와 함께 *"탄약 소진! 재장전하세요"* 음성 경고가 발생합니다.
  • 재장전 쿨다운: 재장전 입력 시 1.2초 후 10발이 완충되며 *"재장전 완료"* 음성이 출력됩니다.
  • 조준선 & 조준점: 총구에서 실제 조준 지점까지 가늘어지는 빔과 조준점이 보이고, 표적 위에 조준점이 오면 팀 색 고정 링이 나타납니다.
  • 명중 효과: 표적이 맞으면 섬광·파편·불꽃과 함께 점수 팝업(예: +2 정보)이 떠오르고, Quest 컨트롤러가 진동합니다.
  • 표적 점수: 정보 · 통신 2점, 제어 · 회로 · 인공 · 전자 1점, 기계 · 전기는 맞히면 1점 감점입니다. 표적 위 라벨에 점수(2점 · 1점 · 빨간 -1점)가 함께 보입니다.
  • 감점 표적 (기계 · 전기): 맞히면 빨간 -1 기계 팝업과 낮은 경고음이 나고 연속 명중이 끊기며, 명중 수에 들어가지 않아 명중률도 내려갑니다. 점수는 0보다 작아질 수 있습니다. 맞히지 않으면 8초 뒤 스스로 사라지고, 경기장에는 난이도별로 한 번에 1 · 2 · 3개(쉬움 · 보통 · 어려움)까지만 나옵니다. PC 화면의 조준점은 감점 표적 위에서 빨갛게 바뀝니다.

🥊 1:1 실시간 PvP 매칭

  • 1P (시안): 1번 자리 플레이어 (플랫폼 왼쪽 시안 발판)
  • 2P (마젠타): 2번 자리 플레이어 (플랫폼 오른쪽 마젠타 발판)

CYBER AI RIVAL

🤖 2P 부재 시 Cyber AI 봇 자동 참전

상대방이 접속하지 않은 1인 플레이 환경에서는 인공지능 라이벌이 자동 출전합니다.

  • 물리적 3D 레이캐스트 판정: AI 총구의 실제 3D 각도와 표적 메시의 교차 여부를 물리적으로 정밀 검증하여, 조준선이 어긋난 치팅 명중을 원천 차단했습니다.
  • 인간 반응 지연 & 예측 사격: 난이도별로 사람과 유사한 0.3~1.4초의 인지 지연 후 사격하며, 어려움 난이도에서는 비행 벡터를 계산하는 선도 예측 사격(Lead Aiming)을 구사합니다.
  • 난이도별 AI 가변 실력 (밸런싱): Easy(명중률 약 30%, 쿨다운 2.8초), Normal(명중률 약 50%, 쿨다운 2.0초, 인간 플레이어 승리 가능 밸런싱), Hard(명중률 약 75%, 쿨다운 1.25초)로 친화적으로 조정되었습니다.
  • AI 탄약 & 재장전: AI 또한 10발 소진 시 난이도별(1.0~2.2초) 재장전 상태에 돌입합니다.
  • 감점 표적 피하기: AI도 기계 · 전기 감점 표적을 노리지 않습니다. 어려움은 항상 피하고, 보통 · 쉬움은 사람처럼 가끔 헷갈려 노리기도 합니다. 감점 표적이 다른 표적 앞을 지나가면 AI도 실수로 맞힐 수 있습니다.

INSTANT ACCESS

🔗 관람 모드 원클릭 접속 방법

누구나 브라우저만 열면 별도 장비 없이 관람 가능합니다.

방법 1. URL 파라미터 (권장): 주소창에 아래 주소를 입력하면 UI 조작 없이 바로 관전 화면으로 시작됩니다. 그다음 F11로 전체 화면:
http://192.168.1.150:3000/?role=spectator

방법 2. 메인 메뉴 버튼: 메인 메뉴의 [관전 화면으로] 버튼(관전 모니터로 정한 기기는 [관전 화면 시작])을 누르거나, [환경설정] › 이 기기 › 기기 역할에서 관전을 고릅니다.

🔊 소리: 브라우저 정책상 화면을 한 번도 클릭하지 않은 페이지는 소리가 막힙니다. 이때 TV 오른쪽 위에 "화면을 한 번 클릭하면 소리가 나요"가 뜨니, 화면을 한 번 클릭하거나 아무 키나 누르세요(F11·Esc로는 켜지지 않음).
TV 소리 켜기·끄기: 마우스를 움직이면 나타나는 오른쪽 위 [소리 끄기]/[소리 켜기] 버튼 또는 M 키. 꺼 두면 오른쪽 위에 "소리 꺼짐"이 표시됩니다. 소리 설정은 기기마다 저장됩니다.
클릭 없이 소리 내기 (전시용 PC 권장): 크롬(엣지도 같음) 바로가기 › 속성 › 대상 끝에 다음 옵션을 붙여 실행합니다. --user-data-dir은 크롬이 이미 켜져 있어도 옵션이 적용되게 하고, --kiosk는 전체 화면으로 엽니다(닫기: Alt+F4).
--autoplay-policy=no-user-gesture-required --user-data-dir=C:\booth-tv --kiosk http://192.168.1.150:3000/?role=spectator

🖥️ 관전 화면 3가지 (자동 전환)

  • 대기 화면: 경기가 없을 때 AI 사격 시연(사격·명중 효과음만 작게, 음성 안내 없음)을 배경으로 게임 소개, 하는 방법, 표적 점수(정보 · 통신 2점, 제어 · 회로 · 인공 · 전자 1점, 기계 · 전기 -1점), 다음 도전자, 최근 경기를 보여 줍니다.

  • 운영 버튼: 마우스를 움직이면 오른쪽 위에 나타납니다. 경기 중에는 [일시정지] · [경기 중단], 언제나 [소리] · [순위표] · [설정] · [매뉴얼]이 있습니다. 관전 화면에는 [경기 시작]이 없습니다. 경기는 선수가 준비해야 시작하고(친구 대결은 둘 다 준비하면 시작), 관전 PC는 보기 · 일시정지 · 중단만 합니다.
  • 관전 화면의 설정 창: 경기 설정(모든 화면 공통) · 소리 · 이 기기(역할 · 서버 주소)만 있습니다. 경기 중에 설정 창을 열었다가 ESC로 닫아도 경기는 계속됩니다.

❓ 8. 자주 묻는 질문 & 문제 해결 (FAQ & Troubleshooting)

Q1. Quest 2 브라우저에서 [VR 배틀 시작] 버튼을 눌러도 반응이 없거나 연결할 수 없다고 뜹니다. ▼
A. W3C 보안 규정으로 인해 사설 IP 접속 시 WebXR이 기본 차단된 상태입니다. 매뉴얼 2번 항목에 안내된 대로 Quest 2 브라우저에서 chrome://flags 접속 → Insecure origins treated as secure에 http://<PC_IP>:3000을 등록하고 [Enabled]로 변경한 뒤 브라우저를 재시작(Relaunch)하세요.
Q2. 눈차크 하드웨어가 없어도 Quest 2 단독으로 플레이할 수 있나요? ▼
A. 네, 100% 가능합니다! Meta Quest 2 순정 터치 컨트롤러를 쥐고 손을 겨누면 6DoF 모션 추적으로 블래스터가 실시간으로 손동작을 따라갑니다. 검지 방아쇠로 사격하고 중지 그립 버튼으로 재장전할 수 있습니다.
Q3. 관람 모드(Observer)에서 카메라 시점을 어떻게 변경하나요? ▼
A. 키보드 숫자 키 [1](스타디움), [2](1P 시점), [3](2P 시점), [4](궤도 회전)을 누르거나, 마우스를 움직이면 화면 오른쪽 위에 나타나는 카메라 버튼을 눌러 바꿀 수 있습니다.
Q4. 한국어 오퍼레이터 음성이 들리지 않습니다. ▼
A. 1) 오른쪽 위 [환경설정] › 소리에서 음성 안내가 켜기이고 음성 크기가 0%가 아닌지 확인하세요.
2) 옆에 있는 [들어 보기] 버튼을 눌러 보세요.
3) 브라우저 정책상 화면을 한 번 클릭(또는 키 입력)하기 전까지는 소리가 나지 않습니다. 관전 TV 오른쪽 위에 "화면을 한 번 클릭하면 소리가 나요"가 보이면 화면을 한 번 클릭하세요. 전시용 PC는 위 관전 모드 안내의 크롬 실행 옵션을 쓰면 클릭하지 않아도 됩니다.
4) 관전 TV 오른쪽 위에 "소리 꺼짐"이 보이면 M 키나 [소리 켜기] 버튼으로 켜세요.
5) 관전 화면의 대기용 AI 시연은 사격·명중 효과음만 작게 나고 음성 안내는 나오지 않습니다. 실제 경기가 시작되면 음성 안내도 나옵니다.
Q5. Quest 2에서 PC 웹사이트가 열리지 않고 무한 로딩이 발생합니다. ▼
A. 1) PC와 Quest 2가 동일한 Wi-Fi에 연결되어 있는지 확인하세요.
2) PC에서 ipconfig로 확인한 IPv4 주소가 정확한지 점검하세요.
3) Windows 방화벽이 포트 3000(Next.js)과 8000(FastAPI)을 차단하고 있지 않은지 매뉴얼 1.4 항목의 PowerShell 방화벽 규칙을 적용하세요.
Q6. 혼자 접속했는데 AI 봇이 조준을 이상하게 하거나 치팅처럼 맞추지 않나요? ▼
A. Cyber Strike VR Arena v1.3에서는 실제 물리적 3D 레이캐스트(Raycast)를 통해 AI 총구와 타겟의 교차를 정밀 검증합니다. 또한 인간 플레이어가 승리할 수 있도록 보통 난이도 기준 반응 속도 0.65~0.95초, 사격 쿨다운 약 2.0초, 명중률 50% 수준으로 밸런싱되어 있습니다.
Q7. npm run dev를 실행하니 "Module not found: troika-three-text" 오류가 납니다. ▼
A. VR 안 글자를 그리는 새 패키지가 아직 설치되지 않은 것입니다. 인터넷이 되는 곳에서 frontend 폴더로 이동해 npm install을 한 번 실행한 뒤 다시 npm run dev를 실행하세요. 코드를 새로 받을 때마다 한 번씩 해 주면 됩니다.
Q8. VR 화면이 끊기거나 느립니다. 성능을 확인하는 방법이 있나요? ▼
A. 1) 주소 끝에 ?debug=perf를 붙여 접속하면(예: http://192.168.1.150:3000/?role=p1&debug=perf) 화면에 fps와 draw call 수가 표시됩니다. VR에서는 총을 들지 않은 손 옆에 작게 보입니다. Quest 2는 72fps가 정상입니다.
2) Quest 브라우저는 자동으로 낮은 그래픽 품질을 씁니다. PC에서도 품질을 낮추려면 주소에 ?quality=low를 붙이세요(높이려면 ?quality=high).
Q9. 1P와 2P(또는 관전 TV)의 경기장 테마나 표적 모양이 다르게 보입니다. ▼
A. 경기 설정(테마 · 표적 모양 · 난이도)은 모든 화면 공통이라 어느 기기에서 바꿔도 1P · 2P · 관전 화면이 함께 바뀝니다. 그래도 다르게 보이면 ① 코드를 업데이트한 뒤 새로고침하지 않은 화면이 있는지 보고 모든 화면(Quest 2대 · 관전 TV)을 새로고침하세요. ② 서버(server 폴더)도 새 코드로 바꾸고 다시 켰는지 확인하세요. 예전 서버는 설정을 맞추지 않아 기기마다 따로 적용되고, 설정 창에 "지금은 이 기기 화면에만 적용돼요"가 보입니다.
