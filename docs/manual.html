📦 1. 게임 설치 및 설정 가이드 (Game Installation & Setup)

개발 PC 환경(Windows / macOS / Linux)에서 백엔드 중계 서버와 프론트엔드 웹 게임을 처음 설치하고 실행하는 단계별 공식 절차입니다.

01

사전 필수 런타임 및 네트워크 환경 준비

본 게임 시스템을 원활하게 구동하기 위해 아래 런타임 및 네트워크 조건을 확인합니다.

  • Node.js: v18.17.0 이상 권장 (LTS 버전, 터미널에서 node -v 로 확인)
  • Python: v3.10 이상 권장 (터미널에서 python --version 으로 확인)
  • 동일 Wi-Fi 네트워크: 개발 PC와 Meta Quest 2 헤드셋이 반드시 동일한 공유기(같은 서브넷)에 연결되어 있어야 합니다.
📌 개발 PC의 사설 IP(IPv4) 확인 방법:
Windows PowerShell 또는 명령 프롬프트(CMD)에서 ipconfig 실행 → 무선 LAN 어댑터의 IPv4 주소(예: 192.168.1.150 또는 192.168.137.1)를 메모해 두세요. 상단 유틸리티 툴바의 입력란에 넣으면 문서 전체에 즉시 동기화됩니다.
02

FastAPI WebSocket 통신 중계 서버 설치 및 실행

FastAPI 서버는 Wii 눈차크/Pico 2 W 하드웨어 신호, Quest 2 6DoF 자세 좌표(20Hz), 사격 이벤트, 타겟 피격 검증을 클라이언트 간에 실시간 중계합니다.

PowerShell / Bash (server/ 디렉토리) 
# 1. 서버 디렉토리 이동
cd server

# 2. 필수 라이브러리 설치 (FastAPI, Uvicorn, WebSockets 등)
pip install -r requirements.txt

# 3. 중계 서버 백그라운드 구동
python run.py
💡 서버 구동 검증 방법
브라우저에서 http://localhost:8000/api/status에 접속하여 아래와 같이 정상 JSON이 응답되는지 확인합니다.
{"pico_connected":false, "game_clients_count":0, "status":"online"}
Swagger 대화형 API 문서는 http://localhost:8000/docs에서 열람 가능합니다.
03

Next.js 16 웹 게임 클라이언트 설치 및 실행

Next.js 16 (Turbopack, TypeScript) 기반의 3D 사격장 웹 애플리케이션 의존성을 설치하고 개발 서버를 가동합니다.

PowerShell / Bash (frontend/ 디렉토리) 
# 1. 프론트엔드 디렉토리 이동
cd frontend

# 2. npm 패키지 의존성 설치
npm install

# 3. 개발 서버 구동 (포트 3000)
npm run dev
⚙️ Next.js 서브넷 IP 허용 설정 (HMR 및 Cross-Origin 차단 방지):
frontend/next.config.ts 파일의 allowedDevOrigins 목록에 개발 PC의 IP 대역이 포함되어 있으므로, 사설 네트워크의 Quest 2 및 모바일 기기에서도 리소스 차단 없이 100% 정상 로드됩니다.

서버가 구동되면 개발 PC 브라우저에서 http://localhost:3000으로 접속하여 네온 글래스모피즘 메인 메뉴 화면이 나타나는지 확인합니다.

04

Windows 방화벽 인바운드 포트 허용 (3000, 8000번 포트)

Quest 2가 PC로 접속할 수 있도록 Windows 방화벽에서 포트 3000(Next.js)과 8000(FastAPI)을 허용합니다.

PowerShell (관리자 권한으로 실행) 
# 3000번(Next.js) 및 8000번(FastAPI) 인바운드 방화벽 규칙 추가
New-NetFirewallRule -DisplayName "Nunchuk VR Game (3000)" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
New-NetFirewallRule -DisplayName "Nunchuk VR Relay (8000)" -Direction Inbound -LocalPort 8000 -Protocol TCP -Action Allow

🥽 2. Meta Quest 2 설치 및 설정 가이드 (Quest 2 WebXR Setup)

Meta Quest 2 / Quest 3 헤드셋을 착용하고 사설 IP(HTTP) 환경에서 W3C 보안 정책을 해제하여 360도 몰입형 WebXR 사격장으로 진입하는 공식 설정법입니다.

⚠️ W3C WebXR 보안 정책 (Secure Context 요구사항) 필독!
Chromium 기반 Meta Quest 브라우저는 W3C 명세에 따라 사설 IP(예: http://192.168.1.150:3000) 접속 시 보안상 WebXR 진입을 기본 차단합니다.
하지만 아래의 1분 설정을 1회만 적용하면, 복잡한 사설 SSL 인증서 설치 없이 안전한 출처(Secure Origin)로 등록되어 360도 Immersive-VR 모드가 무제한 정상 구동됩니다.
01

헤드셋 Wi-Fi 네트워크 동일 공유기 연결 확인

Quest 2 헤드셋의 빠른 설정(Quick Settings) → Wi-Fi 메뉴로 이동하여 개발 PC와 동일한 무선 공유기 SSID에 연결되어 있는지 확인합니다.

💡 5GHz Wi-Fi 환경을 권장하며, 공유기 간 무선 격리(AP Isolation) 옵션이 꺼져 있어야 장치 간 통신이 가능합니다.
02

Quest 2 브라우저 실험적 플래그(chrome://flags) 진입

Quest 2 헤드셋 내부에서 기본 탑재된 [Meta Quest 브라우저] 앱을 실행한 후, 주소창에 아래 주소를 입력하고 이동합니다.

Quest 2 Browser Address Bar 
chrome://flags
03

Insecure origins treated as secure 검색 및 개발 PC IP 등록

실험적 설정 화면 최상단의 [Search flags] 검색창에 insecure를 입력합니다.

검색어: Insecure origins treated as secure

검색 결과로 나타난 해당 항목에서 아래 작업을 순서대로 진행합니다:

  1. 텍스트 입력란에 개발 PC의 주소를 쉼표로 구분하여 입력:
    http://192.168.1.150:3000,http://192.168.1.150:8000
  2. 우측 드롭다운 선택 메뉴를 [Disabled]에서 [Enabled]로 변경합니다.
04

브라우저 재시작(Relaunch) 및 WebXR 사격장 진입

설정을 변경하면 화면 우측 하단에 파란색 [Relaunch] 버튼이 표시됩니다. 이 버튼을 클릭하여 브라우저를 재부팅합니다.

재시작된 브라우저 주소창에 개발 PC 게임 주소를 입력하고 접속합니다:

Quest 2 Browser Address 
http://192.168.1.150:3000
🥽 즉시 VR 사격장으로 진입하는 2가지 방법
1) 화면 중앙의 메인 메뉴 모달에서 대형 [🥽 ENTER VR (Quest 2 대결 입장)] 버튼을 터치하거나,
2) 화면 최하단에 항상 떠 있는 Three.js 공식 [ENTER VR] 버튼을 터치합니다.
헤드셋 공간 권한 허용 팝업이 뜨면 [허용]을 선택하세요. 즉시 360도 네온 아레나로 시야가 전환됩니다!

🔌 3. 하드웨어 결선 가이드 (Wii Nunchuk ↔ Pico 2 W)

Nintendo Wii 눈차크의 I2C 커넥터와 Raspberry Pi Pico 2 W의 핀맵 결선도 및 무선 펌웨어 배포 안내입니다.

PINOUT MAP

눈차크 ↔ Pico 2 W 결선도

Wii Nunchuk Plug Pinout 
       [Wii Nunchuk Plug]
          +---------+
          |  [---]  |  <- 상단 노치
          | 1  2  3 |
          | 4  5  6 |
          +---------+
    1: GND      (White)  -> Pico 2 W Pin 38 (GND)
    2: VCC 3.3V (Red)    -> Pico 2 W Pin 36 (3V3 OUT)
    3: SCL      (Yellow) -> Pico 2 W Pin 7  (GP5 / I2C0 SCL)
    4: NC
    5: NC
    6: SDA      (Green)  -> Pico 2 W Pin 6  (GP4 / I2C0 SDA)

I2C 풀업 저항은 내부 풀업을 활용하거나 4.7kΩ 저항을 3.3V에 연결할 수 있습니다.

CIRCUITPYTHON

Pico 2 W 펌웨어 설정 (settings.toml)

CIRCUITPY/settings.toml 
CIRCUITPY_WIFI_SSID = "My_WiFi_SSID"
CIRCUITPY_WIFI_PASSWORD = "My_Password"
SERVER_HOST = "192.168.1.150"
SERVER_PORT = "8000"

firmware/code.py와 settings.toml을 Pico 2 W 드라이브 루트에 복사하면 전원 인가 즉시 Wi-Fi에 접속하여 50Hz 고속 센서 패킷을 WebSocket 서버로 송신합니다.

⚡ "방아쇠 당겨 즉시 시작" (Pull Trigger to Start)

VR 헤드셋을 착용한 상태에서 복잡한 2D 모달 버튼을 레이저로 조준해 마우스 클릭하듯 터치할 필요가 없습니다!
VR 사격장에 진입하면 눈앞에 3D 홀로그램 배너 [PULL TRIGGER TO START]가 대기하고 있습니다.
오른손 터치 컨트롤러의 검지 방아쇠(Trigger)를 1회 당기는 순간, 홀로그램이 파티클로 사라지며 즉시 60초 카운트다운과 함께 작전이 개시됩니다.

🔫 사격 및 10발 탄창 룰

  • 초기 탄약: 라운드 시작 시 10발 완충 상태로 시작합니다.
  • 탄약 고갈: 잔탄 0발 시 총알이 발사되지 않으며 둔탁한 공이치기 사운드와 함께 *"탄약 소진! 재장전하세요"* 음성 경고가 발생합니다.
  • 재장전 쿨다운: 재장전 입력 시 1.2초 후 10발이 완충되며 *"재장전 완료"* 음성이 출력됩니다.
  • 레이저 조준선 & 타겟 도트: 총구 전방으로 투사되는 네온 빔과 벽면 착탄 도트로 먼 거리의 비행체도 정확히 조준 가능합니다.

📟 가상 블래스터 OLED 디스플레이

PLAYER 1 vs PLAYER 2

🥊 1:1 실시간 PvP 매칭

두 명의 플레이어가 같은 공간에 접속하면 선착순 점수 쟁탈전이 활성화됩니다.

  • P1 (Cyan): 1번 슬롯 접속 플레이어 (좌측 스폰, 하늘색 테마)
  • P2 (Magenta): 2번 슬롯 접속 플레이어 (우측 스폰, 핑크 테마)
  • 6DoF 포즈 릴레이: 상대방 머리(HMD) 아바타의 시선 회전과 블래스터 총구 방향, 발사 시 화염(Muzzle Flash)이 가상 공간에 실시간으로 보입니다.
  • 동일 타겟 경쟁: 먼저 명중시킨 선수가 점수를 획득하며, 표적은 즉시 폭발 파티클과 함께 파괴되어 중복 점수가 방지됩니다.
CYBER AI RIVAL

🤖 2P 부재 시 Cyber AI 봇 자동 참전

상대방이 접속하지 않은 1인 플레이 환경에서는 인공지능 라이벌이 자동 출전합니다.

  • 물리적 3D 레이캐스트 판정: AI 총구의 실제 3D 각도와 표적 메시의 교차 여부를 물리적으로 정밀 검증하여, 조준선이 어긋난 치팅 명중을 원천 차단했습니다.
  • 인간 반응 지연 & 예측 사격: 난이도별로 사람과 유사한 0.3~1.1초의 인지 지연 후 사격하며, Hard 모드에서는 비행 벡터를 계산하는 선도 예측 사격(Lead Aiming)을 구사합니다.
  • 난이도별 AI 가변 실력 (밸런싱): Easy(명중률 약 30%, 쿨다운 2.8초), Normal(명중률 약 50%, 쿨다운 2.0초, 인간 플레이어 승리 가능 밸런싱), Hard(명중률 약 75%, 쿨다운 1.25초)로 친화적으로 조정되었습니다.
  • AI 탄약 & 재장전: AI 또한 10발 소진 시 난이도별(1.0~2.2초) 재장전 상태에 돌입합니다.

http://192.168.1.150:3000/?role=spectator

🤖 AI 봇 실시간 관람 완벽 동기화: 인간 플레이어(1P)의 6DoF 모션뿐만 아니라 AI Rival 봇의 표적 탐색, 헬멧 시선 회전, 블래스터 조준선, 격발 반동(Recoil) 및 총구 화염, 타겟 폭발 파티클과 점수가 관람자에게 실시간(20Hz) 중계됩니다. 또한 1P 부재 시 단독 관람 모드로 접속해도 AI 사격 데모가 자동 구동됩니다.

❓ 8. 자주 묻는 질문 & 문제 해결 (FAQ & Troubleshooting)

Q1. Quest 2 브라우저에서 [ENTER VR] 버튼을 눌러도 반응이 없거나 연결할 수 없다고 뜹니다. ▼
A. W3C 보안 규정으로 인해 사설 IP 접속 시 WebXR이 기본 차단된 상태입니다. 매뉴얼 2번 항목에 안내된 대로 Quest 2 브라우저에서 chrome://flags 접속 → Insecure origins treated as secure에 http://<PC_IP>:3000을 등록하고 [Enabled]로 변경한 뒤 브라우저를 재시작(Relaunch)하세요.
Q2. 눈차크 하드웨어가 없어도 Quest 2 단독으로 플레이할 수 있나요? ▼
A. 네, 100% 가능합니다! Meta Quest 2 순정 터치 컨트롤러를 쥐고 손을 겨누면 6DoF 모션 추적으로 블래스터가 실시간으로 손동작을 따라갑니다. 검지 방아쇠로 사격하고 중지 그립 버튼으로 재장전할 수 있습니다.
Q3. 관람 모드(Observer)에서 카메라 시점을 어떻게 변경하나요? ▼
A. 키보드 숫자키 [1](스타디움 풀샷), [2](1P 숄더뷰), [3](2P 숄더뷰), [4](시네마틱 궤도캠)을 누르거나, 화면 하단 중앙에 나타나는 [BROADCAST CAM] 툴바 버튼을 마우스로 클릭하여 실시간 전환할 수 있습니다.
Q4. 한국어 오퍼레이터 음성이 들리지 않습니다. ▼
A. 1) 상단 [⚙️ SETTINGS]를 열어 KOREAN VOICE BRIEFING이 [ON] 상태이고 볼륨이 0%가 아닌지 확인하세요.
2) 옆에 있는 [🔊 테스트] 버튼을 눌러보세요.
3) 최신 브라우저의 오디오 정책상 최초 1회 화면 클릭(또는 사격) 전까지 브라우저 오디오가 일시 정지되어 있을 수 있습니다.
Q5. Quest 2에서 PC 웹사이트가 열리지 않고 무한 로딩이 발생합니다. ▼
A. 1) PC와 Quest 2가 동일한 Wi-Fi에 연결되어 있는지 확인하세요.
2) PC에서 ipconfig로 확인한 IPv4 주소가 정확한지 점검하세요.
3) Windows 방화벽이 포트 3000(Next.js)과 8000(FastAPI)을 차단하고 있지 않은지 매뉴얼 1.4 항목의 PowerShell 방화벽 규칙을 적용하세요.
Q6. 혼자 접속했는데 AI 봇이 조준을 이상하게 하거나 치팅처럼 맞추지 않나요? ▼
A. Cyber Strike VR Arena v1.3에서는 실제 물리적 3D 레이캐스트(Raycast)를 통해 AI 총구와 타겟의 교차를 정밀 검증합니다. 또한 인간 플레이어가 승리할 수 있도록 Normal 모드 기준 반응 속도 0.4초, 사격 쿨다운 2.0초, 명중률 50% 수준으로 정밀 밸런싱되어 있습니다.
